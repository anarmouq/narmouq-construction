# Narmouq Construction React Template

Responsive one-page React + Vite construction website with:

- Large centered Narmouq logo
- Dark navy and gold brand styling
- Scroll/parallax motion
- Responsive mobile menu
- About, services, projects, and contact sections
- No extra React libraries

## Run the website

Open PowerShell inside this folder and run:

```powershell
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Use inside your existing Vite project

Copy these items into your project:

- `src/App.jsx`
- `src/App.css`
- `src/index.css`
- `src/main.jsx`
- `public/logo.png`

## Customize

Edit the company text, phone number, email, services, and project list in `src/App.jsx`.

The template uses Unsplash image URLs. Replace them with your own project images when ready.
